# Demo Video Checklist

- Open the Vue app through `npm run dev`.
- Show `/boards` and open Product Roadmap.
- Drag a card across columns and confirm the toast, activity rail, and card position update.
- Use the card movement arrow controls to demonstrate keyboard-accessible movement.
- Open a task drawer and close it.
- Use Undo and Redo from the top bar.
- Toggle dark mode from the top bar.
- Open notifications and mark one as read.
- Show settings and explain mocked Supabase-ready realtime controls.
- End with `npm run build` passing.
